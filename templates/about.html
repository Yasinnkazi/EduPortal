About EduPortal

EduPortal is a realistic educational student management portal built to feel and behave like a modern university ERP system. Students can log in, view their profiles and results; staff and administrators can browse the complete student, course and faculty directory.

Behind the polished interface, the application intentionally contains classic SQL Injection vulnerabilities. Every database interaction is written using raw SQL string concatenation with no prepared statements and no input escaping. This makes EduPortal a safe, self-contained laboratory for teaching how SQL Injection works and how it can be prevented.

The Educational Objective
  • Demonstrate how user input flows unsanitised into a SQL query.
  • Show how an attacker can bypass login using ' OR '1'='1.
  • Show how to extract hidden data using UNION SELECT.
  • Explain the fix: prepared statements, parameterised queries and validation.
